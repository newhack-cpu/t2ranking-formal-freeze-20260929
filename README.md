# T2Ranking formal-feature freeze bundle

This bundle is intentionally data-free. It contains only protocol identifiers,
content hashes, and validation receipts needed to establish an externally
verifiable freeze point before formal CPU production.

It does **not** contain queries, documents, qrels, labels, CE scores, model
weights, SSH information, credentials, or internal source trees.

The release remains `draft` until this bundle is published by an external
timestamped service (for example a public Git commit or a persistent archive
record). The publication timestamp and immutable URL/commit must be recorded
outside this directory before formal feature production is authorized.
